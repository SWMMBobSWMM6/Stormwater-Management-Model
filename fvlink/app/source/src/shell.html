FV Link Lab

swmm524-fvlink: finite volume on the conduits you choose, dynamic wave everywhere else · EPA SWMM 5.2.4 in WebAssembly · AI use: see About
Run. Pick a model, list one or more conduits as FV links, and run both engines. Stock EPA SWMM 5.2.4 runs the model without the [FV_LINKS] section; swmm524-fvlink runs it with the section. Everything runs in your browser.
